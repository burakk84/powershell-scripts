# PowerShell Scripts

A small collection of PowerShell tools for Windows and Active Directory administration.

## Scripts

- **[Pc_Analiz.ps1](Pc_Analiz.ps1)** — gathers system and resource details from a remote Windows computer. See [README_Pc_Analiz.md](README_Pc_Analiz.md).
- **[sifre_lock_expire.ps1](sifre_lock_expire.ps1)** — checks an Active Directory account and can unlock it after confirmation. See [README_sifre_lock_expire.md](README_sifre_lock_expire.md).

## Betikler

- **[Pc_Analiz.ps1](Pc_Analiz.ps1)** — uzak bir Windows bilgisayarının sistem ve kaynak bilgilerini toplar. Ayrıntılar: [README_Pc_Analiz.md](README_Pc_Analiz.md).
- **[sifre_lock_expire.ps1](sifre_lock_expire.ps1)** — Active Directory hesabını sorgular ve onayla kilidini açabilir. Ayrıntılar: [README_sifre_lock_expire.md](README_sifre_lock_expire.md).
