# Active Directory User Status & Unlock Tool

An interactive PowerShell script for IT Helpdesk and System Administrators to quickly check Active Directory user account status and unlock locked accounts.

## Features

- Check if a user account is locked
- Display password last set date
- Display password expiration date
- Show account status (Enabled/Disabled)
- Unlock locked Active Directory accounts
- Simple interactive command-line interface
- Lightweight and easy to use

## Requirements

- Windows PowerShell 5.1 or later
- Active Directory PowerShell Module
- Appropriate permissions to query and unlock Active Directory users

## Usage

Run the script in PowerShell:

```powershell
.\AD-UserStatus-Unlock.ps1
```

Enter the username when prompted. The script will display the account status and allow you to unlock the account if necessary.
